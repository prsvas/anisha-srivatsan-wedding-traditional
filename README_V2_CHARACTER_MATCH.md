# V2 Character-Matched Ritual Update

This package preserves the original five illustrations unchanged: Kasi Yathra, Oonjal, Malai Maatral, Kanyadanam and Mangalya Dharanam.

The later ritual artwork has been replaced with a consistent illustrated South Indian wedding character style and includes Sapthapadi, Ammi Midhithal, Metti Dharanam, Arundhati Darshan, Asirvadam, Traditional Tamil Iyer Bhojanam and Nelangu.

Nelangu is also included as programme item 12 and as the final ritual section after the feast.
