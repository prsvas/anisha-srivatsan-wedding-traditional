# Version 2 — Final Corrections

1. **Recipient name placement**
   - 20 pt font.
   - Printed clearly above the first blue writing line on Page 1.
   - Width automatically reduced for unusually long names while remaining on one line.

2. **Invitation PDF presentation**
   - Original invitation artwork retained.
   - Page margins reduced so the invitation artwork occupies more of the printable page.
   - Tamil Page 3 is presented in landscape orientation because the supplied Tamil invitation artwork is landscape, making the text easier to read and using the page area properly.

3. **Event image presentation**
   - Event images are displayed at their natural aspect ratio.
   - Removed fixed-height presentation that could make the artwork appear cropped or stretched.
   - Images use the supplied high-resolution `hq-*` assets.
   - Event rows no longer impose a fixed 500px height.
   - Event images are loaded without lazy-loading delay.

**Important source-image note:** The supplied Kasi Yathra artwork itself has the upper part of the character already cropped in the source image. Website CSS cannot restore pixels that are not present in the source. The layout correction prevents any *additional* cropping by the website. If a fully expanded version of a particular artwork is required, the original uncropped artwork is needed for that event.
